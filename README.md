# Trabalho-III-2

A modelagem das entidades do sistema está concentrada no arquivo modelos.py, que contém as classes Cliente, Funcionário, Quarto, Reserva e a classe abstrata Pessoa. A estrutura das classes segue os princípios do encapsulamento, utilizando atributos privados e propriedades para controle de acesso e validação. A classe Pessoa é definida como abstrata por meio do módulo abc, e suas subclasses implementam comportamentos específicos, permitindo o uso de polimorfismo onde necessário. As relações entre os objetos refletem situações reais do domínio: reservas associam clientes e quartos, o sistema mantém agregações de entidades cadastradas e cada reserva é composta por suas datas e informações específicas.

As regras de negócio são centralizadas no arquivo servicos.py, que contém a classe SistemaReservas. Esta classe é responsável por operações como cadastro de clientes e quartos, consulta de disponibilidade, criação e cancelamento de reservas e listagem das reservas existentes. Toda a validação necessária é realizada nesta camada, garantindo que a interface gráfica permaneça livre de lógica de negócio. Entre as validações implementadas estão a verificação de disponibilidade de quartos, o cálculo do valor total da reserva com base no período informado, a restrição de cancelamento após o prazo estabelecido e a necessidade de revisão do quarto após o checkout.

A interface gráfica está implementada no arquivo gui.py e serve como meio de interação entre o usuário e o sistema. A aplicação utiliza elementos básicos do Tkinter, como janelas, campos de entrada, botões e exibição de mensagens. A interface permite realizar todas as operações essenciais: cadastrar clientes, cadastrar quartos, consultar disponibilidade, realizar reservas, listar reservas e cancelar reservas. Todas as ações acionadas pela interface são repassadas diretamente para os métodos da classe SistemaReservas, garantindo uma separação adequada entre apresentação e lógica de negócio. A interface também utiliza caixas de diálogo para exibir mensagens de confirmação, erro ou informações ao usuário.

Para executar o sistema, basta garantir que todos os arquivos estejam no mesmo diretório e iniciar o arquivo gui.py por meio do interpretador Python. A interface gráfica será exibida automaticamente, possibilitando o uso do sistema sem necessidade de interação via terminal.
